# Jour 2 — Design brief

## 1. Rôle narratif du Jour 2

Le Jour 2 doit être le lendemain émotionnel du Jour 1.

Le Jour 1 pose :

- le malaise ;
- les premières versions ;
- les soupçons ;
- les premiers silences ;
- les premières demandes de couverture ;
- les premières respirations.

Le Jour 2 doit faire remonter les conséquences :

- les versions données la veille ;
- les contradictions ;
- les silences ;
- les dettes ;
- les rapprochements ;
- les limites posées.

Le Jour 2 ne doit pas tout résoudre. Il doit épaissir la situation, rendre les choix du Jour 1 plus visibles, et pousser le joueur à sentir que les versions données hier commencent à vivre chez les autres personnages.

Objectif d’écriture : ne pas accélérer artificiellement vers une révélation. Le Jour 2 doit surtout installer les frictions, les attentes et les petites dettes relationnelles.

## 3. Personnages actifs Jour 2

Proposition de rôle par personnage :

- Sarah : relation domestique, confiance, fatigue, besoin de cohérence. Elle porte la question du retour réel et du poids des versions.
- Camille : tension, limite, refus d’être une parenthèse. Elle porte l’ambiguïté affective et le risque de minimisation.
- Nico : dette, ami/alibi, humour qui commence à coûter. Il porte la question de la couverture et de la loyauté.
- Maya : regard social, groupe, photo, timing. Elle porte la perception extérieure, les indices faibles, les absences visibles.
- Inès : espace calme, fuite possible, douceur à manier avec prudence. Elle porte l’option d’un ailleurs émotionnel, sans romance explicite précipitée.

Le Jour 2 peut ne pas donner le même poids à tout le monde. En revanche, chaque personnage activé doit avoir une raison claire d’exister dans la journée.

## 4. Structure proposée du Jour 2

Structure en blocs, sans dialogues complets à ce stade.

### J2 — Matin

Objectif : faire sentir que la nuit n’a pas effacé le Jour 1.

Pistes :

- Sarah relance sur la cohérence, le retour à la maison, le repas, ou la version donnée hier.
- Camille peut envoyer un message court si la tension a été reconnue, si elle a été minimisée, ou si le joueur l’a laissée sans réponse.
- Nico peut vérifier si sa version tient encore, surtout si le joueur l’a utilisé comme alibi ou lui a demandé une couverture.

Le matin doit être court, lisible, et ne pas lancer toutes les bombes à la fois.

### J2 — Milieu de journée

Objectif : faire remonter le regard social et les espaces de fuite.

Pistes :

- Maya peut revenir sur la photo, le groupe, une absence visible ou une remarque de timing.
- Inès peut proposer une présence calme si le joueur s’est ouvert à elle, ou garder une distance douce si le joueur l’a tenue à distance.
- Nico peut glisser une blague qui masque moins bien son inquiétude.

Le milieu de journée est un bon endroit pour créer de la pression indirecte plutôt qu’une confrontation frontale.

### J2 — Soir

Objectif : poser un choix de priorité sans verrouiller trop tôt toute la suite.

Pistes :

- Sarah ou Camille peut demander une clarification plus frontale.
- Nico peut poser une limite sur la couverture.
- Maya peut faire sentir que le groupe commence à remarquer quelque chose.
- Inès peut devenir une option de calme, mais pas une échappatoire gratuite.

Un choix de priorité peut orienter le Jour 3, mais il ne faut pas créer de gros embranchement irréversible avant validation.

## 5. Règles de savoir

- Sarah ne sait que ce que le joueur lui a dit, plus ce qu’elle ressent dans le quotidien : fatigue, absence, incohérence, distance, retour ou non-retour.
- Camille ne sait pas les versions données à Sarah sauf si le joueur les mentionne. Elle peut sentir l’évitement, la tension ou la minimisation.
- Nico ne sait pas qu’il est utilisé sauf si le joueur l’a impliqué, lui a demandé une couverture, ou s’il le soupçonne à partir de ce qu’on lui demande.
- Maya observe le groupe, les absences, les photos et les timings. Elle ne connaît pas la vérité.
- Inès ressent une faille, une fatigue ou une fuite. Elle ne sait rien factuellement.

Règle générale : les personnages peuvent interpréter, se tromper, projeter, remarquer ; ils ne doivent pas lire les flags.

## 6. Héritage du système J1

Le Jour 2 doit réutiliser les conventions validées dans `docs/j1_v2_mvp_conventions.md` :

- choix uniques `_single_reply_` pour les micro-réponses manuelles ;
- choix multiples narratifs pour les vraies postures ;
- médias `type: "media"` si un média apporte quelque chose ;
- non-réponse / `left_open` si elle a un intérêt de rythme ou de conséquence ;
- reprises tardives seulement si elles ont un vrai intérêt narratif.

Ne pas tout complexifier dès le J2. Le J2 doit rester jouable et testable.

Les scènes J2 doivent conserver une structure claire : entrée, quelques messages, un ou deux choix significatifs, conséquence lisible.

## 7. Risques à éviter

- multiplier trop vite les branches ;
- faire parler les personnages comme s’ils avaient lu les flags ;
- créer trop de choix par scène ;
- transformer Maya en détective omnisciente ;
- transformer Inès en romance explicite trop tôt ;
- rendre Sarah uniquement accusatrice ;
- rendre Camille uniquement tentatrice ;
- faire de Nico un simple outil d’alibi ;
- confondre conséquence émotionnelle et révélation factuelle ;
- créer des médias qui deviennent des preuves absolues ;
- rendre le Jour 2 injouable par accumulation de dépendances.

## 8. Proposition de MVP Jour 2

MVP raisonnable :

- 4 à 5 conversations principales maximum ;
- 1 ou 2 scènes de respiration ;
- 1 média maximum au départ ;
- 1 système de reprise tardive uniquement si nécessaire ;
- pas de gros embranchement irréversible avant validation ;
- peu de nouveaux flags, mais des flags bien nommés ;
- priorité à la cohérence des conséquences J1 plutôt qu’à l’expansion de contenu.

Proposition de première tranche :

1. une relance Sarah matin ;
2. une réponse Camille ou Nico selon flags forts ;
3. un bloc social Maya/Inès milieu de journée ;
4. une clarification soir avec choix de priorité ;
5. une respiration courte si le rythme devient trop dense.

## 9. À décider avant écriture

Décisions à prendre avant de rédiger les dialogues J2 :

- Le Jour 2 commence-t-il automatiquement après Sarah repas/Nico respiration, ou après une transition explicite de fin de journée ?
- Toutes les conversations J2 sont-elles visibles dès le matin ?
- Qui écrit en premier ? Sarah par défaut, ou le premier contact dépend-il des flags J1 ?
- Le joueur doit-il choisir une priorité dans la journée ?
- Quels flags J1 sont vraiment structurants pour le MVP J2 ?
- Le Jour 2 doit-il contenir un événement de groupe ?
- Le média Maya doit-il avoir une conséquence plus tard ?
- Les scènes de respiration J2 doivent-elles être automatiques ou conditionnelles ?
- Faut-il créer un nouveau bloc système `day_2` séparé ou prolonger le mécanisme de disponibilité existant ?
- Quel niveau de dette Nico doit-il explicitement poser ?

## 10. Tests futurs à prévoir

Prévoir des tests de cadrage et de non-régression :

- les flags J1 référencés par J2 existent ;
- les conversations J2 ne cassent pas J1 ;
- les choix uniques suivent la convention `_single_reply_` ;
- les choix uniques ne portent pas d’effets ;
- les textes des choix uniques correspondent aux nodes player associés ;
- les choix multiples restent de vraies postures narratives ;
- les personnages ne deviennent pas omniscients ;
- les transitions J1 → J2 restent propres ;
- `Messages non lus...` continue de guider vers les nouveaux messages ;
- les médias J2, s’il y en a, respectent le fallback et le zoom ;
- les reprises tardives éventuelles ne bouclent pas ;
- le validator J1 V2 reste vert pendant l’intégration J2.

Le premier test J2 devrait probablement vérifier la structure de disponibilité et l’absence de régression J1 avant même d’écrire les dialogues complets.
