# J3 — Audit signatures personnages, temporalité, quotidien et croisements

## 1. Problème global

Le J3 V2 est cohérent sur le fond, mais il reste trop mécanique dans sa forme.

Les audits précédents ont validé :
- la cohérence des savoirs ;
- les flags et effets ;
- le runtime progressif ;
- le polish d’oralité de base ;
- les médias Sarah/Nico avec réactions.

Mais une relecture narrative fait apparaître un problème plus profond : les scènes donnent parfois l’impression d’avoir été construites sur le même moule.

Pattern trop présent :
```text
rappel de la veille
→ micro-réponse
→ analyse émotionnelle
→ choix central
```

Ce pattern garantit la clarté, mais il réduit la sensation de vie. Les personnages paraissent parfois attendre leur tour pour résumer ce qu’ils ont compris, au lieu d’exister dans une journée, avec un lieu, une humeur, une activité et un rapport particulier au joueur.

Le problème n’est donc pas la cohérence.
Le problème est le manque de :
- variété ;
- ancrage temporel ;
- quotidien ;
- signatures de voix ;
- respiration ;
- croisements vivants entre fils de discussion.

## 2. Objectif de correction future

T204 ne devra pas tout réécrire.
Il devra rendre les scènes :
- moins stéréotypées ;
- plus incarnées ;
- plus ancrées dans un moment précis ;
- plus différenciées par personnage ;
- plus longues quand la complicité ou l’hésitation le justifie ;
- plus connectées entre elles sans omniscience ;
- plus capables de créer une tension de messagerie.

Le joueur doit sentir que :
- Sarah a une journée ;
- Nico a une vie ;
- Camille travaille, bouge, hésite ;
- Maya observe le social ;
- Inès répond depuis un rythme plus intérieur ;
- les messages arrivent dans un quotidien, pas dans un vide narratif.

## 3. Temporalité — problème actuel

Le jeu avance par jours, mais les blocs de la journée sont encore trop peu visibles.

On comprend qu’on est au Jour 3, mais on ressent peu :
- le début de matinée ;
- la pause déjeuner ;
- le milieu de journée ;
- la fin d’après-midi ;
- la soirée ;
- la nuit.

Cela affaiblit plusieurs éléments de gameplay narratif :
- les alibis ;
- les délais de réponse ;
- les tensions croisées ;
- le quotidien ;
- l’humeur des personnages ;
- les opportunités de choix.

La temporalité devrait permettre au joueur de comprendre :
- pourquoi un personnage écrit maintenant ;
- pourquoi il répond tard ;
- ce qu’il est en train de faire ;
- ce que le joueur risque en répondant ou en retardant ;
- si une réponse peut en parasiter une autre.

## 4. Temporalité — proposition de blocs

Il ne faut pas simplement plaquer des labels mécaniques “Matin / Midi / Soir”.
On peut utiliser des repères plus narratifs.

### Début de matinée

Ambiance :
- réveil ;
- prudence ;
- fatigue ;
- premières vérifications ;
- petits gestes ou absence de gestes.

Personnages pertinents :
- Sarah ;
- Nico.

Usage :
- Sarah observe les gestes.
- Nico répond tard ou fait une vanne pour éviter d’entrer trop vite dans le sérieux.

Exemples :
```text
Début de matinée — les messages ont encore le goût du réveil.
```

```text
Ce matin, j’ai attendu avant d’écrire. Encore.
```

### Milieu de journée

Ambiance :
- travail ;
- interruption ;
- messages plus courts ;
- tension contenue ;
- pauses.

Personnages pertinents :
- Camille ;
- Maya.

Usage :
- Camille peut être au travail ou en pause.
- Le joueur peut la taquiner pendant une journée de travail.
- Maya peut observer un décalage social ou une ambiance.

Exemples :
```text
pause de trois minutes.
j’en utilise une pour te dire que ta limite m’agace encore.
```

```text
je suis censée bosser, donc évidemment je t’écris.
```

### Pause / midi

Ambiance :
- réponses rapides ;
- repas ;
- “je peux pas trop parler” ;
- disponibilité partielle ;
- tension qui doit tenir dans un court échange.

Usage :
- créer des contraintes naturelles ;
- éviter que chaque discussion soit un long face-à-face émotionnel ;
- rendre les délais plus crédibles.

Exemples :
```text
je mange dans dix minutes, donc t’as une fenêtre de réponse très officielle.
```

```text
pause café. je vais faire semblant que c’est une pause normale.
```

### Fin d’après-midi

Ambiance :
- fatigue ;
- messages qui reprennent ;
- tensions du matin qui reviennent ;
- premières collisions entre fils.

Usage :
- Maya peut remarquer une ambiance.
- Camille peut revenir sur une phrase.
- Nico peut proposer autre chose.
- Sarah peut constater un geste ou son absence.

Exemples :
```text
fin de journée, et bizarrement les messages ont toujours pas rangé le problème.
```

### Soirée

Ambiance :
- disponibilité plus intime ;
- gaming ;
- sortie ;
- solitude ;
- contradictions plus visibles ;
- alibi potentiel.

Personnages pertinents :
- Nico ;
- Inès ;
- Sarah.

Usage :
- Nico peut proposer une soirée jeux vidéo chez lui.
- Sarah peut voir si le joueur tient ses gestes.
- Inès peut répondre avec douceur.
- Le joueur peut utiliser la soirée comme vraie respiration ou comme fuite.

Exemples :
```text
ce soir je lance la console. si tu viens, tu parles pas pendant la première game.
```

```text
je ne savais pas si c’était une bonne idée de répondre ce soir.
```

### Nuit

Ambiance :
- réponses tardives ;
- messages effacés ;
- fatigue ;
- ambiguïté ;
- tension sexuelle future.

Usage :
- à garder pour J4/J5 ou plus tard ;
- ne pas tout consommer en J3.

Exemples :
```text
j’ai écrit trois messages et j’en ai effacé deux.
```

```text
il est trop tard pour répondre simplement, non ?
```

## 5. Marqueurs temporels possibles

### Option A — nodes système simples

Exemples :
```text
— Début de matinée —
— Pause déjeuner —
— Fin d’après-midi —
— Soirée —
```

Avantages :
- très simple ;
- testable ;
- lisible.

Risques :
- mécanique si répété partout ;
- peut casser l’immersion SMS si trop fréquent.

### Option B — cartes / écrans de transition

Exemples :
```text
Début de soirée
Les réponses deviennent moins pratiques.
```

```text
Pause midi
Tout le monde répond vite. Personne ne répond vraiment.
```

Avantages :
- très lisible ;
- donne une structure forte à la journée ;
- peut devenir un élément d’interface agréable.

Risques :
- nécessite probablement un vrai design UI ;
- peut alourdir le MVP.

### Option C — repères intégrés aux messages

Exemples :
```text
je suis au boulot, je peux pas trop écrire.
```

```text
je viens de rentrer.
```

```text
je lance le PC dans dix minutes.
```

```text
pause café, donc j’ai le droit d’être pénible trois minutes.
```

Avantages :
- naturel ;
- pas besoin d’UI ;
- permet d’incarner les personnages.

Risques :
- moins visible si ce n’est pas systématique.

### Recommandation

Pour T204 :
- utiliser surtout l’option C dans les dialogues ;
- ajouter éventuellement quelques nodes système très sobres si déjà supportés ;
- reporter les cartes de transition à une tâche UI dédiée.

## 6. Signatures attendues par personnage

### Sarah

Signature :
- quotidien ;
- gestes ;
- détails domestiques ;
- fatigue douce ;
- blessure contenue ;
- besoin de concret ;
- attachement encore présent.

Sarah doit moins commencer par :
```text
Je repense à ta phrase d’hier.
```

Elle peut commencer par :
- une tasse ;
- une table ;
- une absence de geste ;
- un message écrit puis retenu ;
- un détail du matin ;
- une petite remarque qui cache une blessure.

Exemples :
```text
J’ai laissé ta tasse sur la table.
```

```text
Je sais, c’est bête, mais j’ai regardé si tu avais pensé à un truc simple.
```

```text
Ce matin, j’ai attendu avant d’écrire. Encore.
```

Rapport au joueur :
- intime ;
- conjugal ;
- usé mais pas détaché ;
- elle ne veut pas seulement des mots ;
- elle observe les détails parce qu’elle n’a plus assez confiance dans les grandes phrases.

À éviter :
- Sarah trop diagnostique ;
- trop de concepts ;
- trop de phrases parfaites ;
- trop de “je repense à...”.

### Nico

Signature :
- vanne ;
- retard ;
- gaming ;
- fausse légèreté ;
- loyauté ;
- limite amicale ;
- vie sociale hors joueur.

Nico doit moins ressembler à un conseiller.
Il doit pouvoir proposer autre chose que parler du problème.

Exemples :
```text
update : je suis vivant. émotionnellement discutable, mais vivant.
```

```text
j’ai failli répondre hier, puis j’ai choisi la lâcheté productive.
```

```text
ce soir je lance la console. si tu viens, tu parles pas pendant la première game.
```

Rapport au joueur :
- pote ;
- complice ;
- peut charrier ;
- peut aider ;
- mais refuse d’être un pare-feu permanent.

Idée forte :
Nico peut proposer une soirée jeux vidéo chez lui.

Cela peut servir à :
- donner de la respiration ;
- créer un alibi possible ;
- montrer une vraie amitié ;
- créer une tension avec Sarah si le joueur utilise Nico pour fuir ;
- faire sentir que Nico a sa propre disponibilité.

À éviter :
- Nico trop moraliste ;
- Nico clown permanent ;
- Nico conseiller conjugal ;
- Nico qui sait trop de choses.

### Camille

Signature :
- tension ;
- sous-entendu ;
- travail / pauses ;
- provocation légère ;
- limites ;
- désir contenu ;
- phrases qui testent le joueur.

Camille doit moins expliquer son rôle.
Elle peut écrire depuis un moment concret :
- au travail ;
- en pause ;
- en marchant ;
- en repassant devant un lieu ;
- depuis un café ;
- entre deux obligations.

Exemples :
```text
pause de trois minutes.
j’en utilise une pour te dire que ta limite m’agace encore.
```

```text
je suis censée bosser, donc évidemment je t’écris.
```

```text
ta limite tient toujours ?
```

Rapport au joueur :
- trouble ;
- jeu dangereux ;
- reconnaissance désirée ;
- refus d’être minimisée ;
- tension sexuelle future conditionnée au respect.

À éviter :
- Camille trop théorique ;
- Camille qui explique trop la scène ;
- répétitions “limite / sortie / endroit” ;
- Camille récompense sexuelle.

### Maya

Signature :
- social ;
- ironie ;
- rythme vif ;
- observation ;
- piques ;
- groupe ;
- fausse légèreté.

Maya doit moins être analyste.
Elle doit donner l’impression d’être dans le monde social.

Exemples :
```text
bon. j’ai fait semblant de rien voir pendant presque 24h.
```

```text
j’ai gagné combien de points si je ne pose pas la question ?
```

```text
l’ambiance a une tête bizarre aujourd’hui. oui, j’ai décidé que les ambiances avaient des têtes.
```

Rapport au joueur :
- complice mais pas dupe ;
- elle voit les décalages ;
- elle peut protéger le groupe ;
- elle ne doit pas devenir détective.

À éviter :
- Maya preuve sociale ;
- Maya détective ;
- Maya porte-parole ;
- Maya qui sait au lieu de sentir.

### Inès

Signature :
- hésitation ;
- douceur ;
- silence ;
- distance ;
- retenue ;
- présence non invasive.

Inès doit moins formuler parfaitement.
Elle peut commencer par :
- un message effacé ;
- une hésitation ;
- un “je ne sais pas si je devrais répondre” ;
- un détail calme ;
- une phrase qui laisse du vide.

Exemples :
```text
j’ai écrit trois messages et j’en ai effacé deux.
```

```text
je ne savais pas si c’était une bonne idée de répondre ce soir.
```

```text
je suis là, mais je ne veux pas devenir un endroit où tu te caches.
```

Rapport au joueur :
- douceur ;
- prudence ;
- calme ;
- elle refuse d’être une fuite ;
- possible intimité future seulement si fuite basse.

À éviter :
- Inès thérapeute ;
- Inès trop lucide ;
- Inès qui explique parfaitement le mécanisme ;
- Inès récompense de calme.

## 8. Audit des structures de scène

La plupart des scènes suivent actuellement :

```text
rappel J2
→ micro-réponse joueur
→ clarification personnage
→ choix central
```

Cette structure peut rester pour certaines variantes, mais il faut la casser régulièrement.

Alternatives possibles :

### Démarrer par le présent

```text
J’ai laissé ta tasse sur la table.
```

### Démarrer par une activité

```text
je suis censée bosser, donc évidemment je t’écris.
```

### Démarrer par une blague

```text
update : je suis vivant.
```

### Démarrer par un silence

```text
j’ai écrit trois messages et j’en ai effacé deux.
```

### Démarrer par une contrainte

```text
pause de trois minutes.
```

### Démarrer par une invitation

```text
ce soir je lance la console.
```

### Démarrer par une observation sociale

```text
bon. j’ai fait semblant de rien voir pendant presque 24h.
```

## 9. Audit des scènes trop rapides

Certaines scènes gagneraient à avoir 2 à 4 messages supplémentaires.

### Sarah — branche gestes + photo

Problème :
La photo est commentée, mais le joueur ne peut pas réagir.
Le média devient encore un insert plutôt qu’une mini-discussion.

Direction T204 :
- photo ;
- micro-réponse joueur ;
- Sarah répond ;
- reprise du fil.

### Nico — branche vie propre + photo

Problème :
La photo donne de la vie à Nico, mais il manque une réaction joueur.
Le potentiel de complicité est sous-utilisé.

Direction T204 :
- photo ;
- micro-réponse joueur ;
- Nico esquive ;
- proposition éventuelle de soirée jeux vidéo ;
- retour au fil.

### Camille — tension / limite

Problème :
Camille verbalise vite la fonction de la limite.
Elle pourrait davantage tester le joueur.

Direction T204 :
- contexte travail / pause ;
- sous-entendu ;
- question plus courte ;
- tension qui se construit.

### Maya — autres remarquent

Problème :
La scène est cohérente, mais pourrait être plus sociale.
Elle pourrait contenir une micro-observation concrète.

Direction T204 :
- “quelqu’un a changé de sujet” ;
- “le groupe répond bizarrement” ;
- “je dis pas que ça veut dire quelque chose”.

### Inès — refuge

Problème :
La scène est bonne, mais elle explique encore beaucoup.
Elle pourrait laisser plus de silence.

Direction T204 :
- hésitation ;
- phrase plus courte ;
- moins de théorie ;
- plus de retenue.

## 10. Audit des photos comme mini-discussions

### Sarah photo matin

Actuel :
```text
Sarah : Alors je vais regarder les gestes.
→ photo
Sarah : C’est pas grand-chose.
Sarah : Mais c’est le genre de petit truc que je remarque maintenant.
Sarah : Pas pour te piéger.
```

Problème :
Le joueur ne réagit pas à la photo.
Sarah commente seule.

Proposition T204 :
```text
Sarah : Alors je vais regarder les gestes.
→ photo
Joueur : Tu veux que je voie quoi ?
Sarah : Rien d’énorme.
Sarah : Juste ce genre de petit truc.
Sarah : Le genre de chose qui dit plus que “je vais faire attention”.
Sarah : Pas pour te piéger.
```

Alternative joueur :
```text
C’est quoi ?
```
ou
```text
Tu me montres ça pourquoi ?
```

### Nico photo sortie

Actuel :
```text
Nico : disons que quelqu’un m’a écrit.
→ photo
Nico : preuve que j’ai une vie. floue, certes.
Nico : mais une vie quand même.
Nico : et pour une fois...
```

Problème :
Le potentiel de complicité est bon, mais le joueur ne réagit pas.
La photo peut devenir plus vivante.

Proposition T204 :
```text
Nico : disons que quelqu’un m’a écrit.
→ photo
Joueur : C’est où ça ?
Nico : ah.
Nico : monsieur découvre que je peux être localisé ailleurs que dans tes problèmes.
Nico : et pour une fois...
```

Variante plus complice :
```text
Joueur : Monsieur a une vie ?
Nico : floue, mais homologuée.
```

## 11. Croisements dynamiques à préparer

C’est le point le plus important pour J4 et au-delà.

Les fils de discussion doivent pouvoir s’influencer sans rendre les personnages omniscients.

### Exemple fort : Sarah ↔ Nico

Situation :
Sarah remarque une incohérence.
Avant de répondre, le joueur peut contacter Nico pour vérifier sa version.

Structure possible :
1. Sarah écrit :
```text
Il y a un détail qui colle pas.
```

2. Le joueur peut :
- répondre directement ;
- temporiser ;
- contacter Nico avant de répondre.

3. Si le joueur contacte Nico :
```text
Joueur : Sarah a remarqué un truc.
Nico : merveilleux.
Nico : on entre donc dans la phase “service après-vente du mensonge approximatif”.
```

4. Nico peut :
- aider ;
- refuser ;
- corriger ;
- aggraver par fatigue.

5. Retour à Sarah :
- réponse plus propre mais plus tardive ;
- ou réponse immédiate mais fragile.

Effets possibles :
- `risque_exposition`
- `dette_nico`
- `confiance_sarah`
- `distance_sarah`
- `coherence`
- `fatigue_emotionnelle`

### Nico soirée jeux vidéo

Nico peut proposer :
```text
ce soir je lance la console.
si tu viens, tu parles pas pendant la première game.
```

Fonctions possibles :
- respiration réelle ;
- fuite ;
- alibi ;
- marque d’amitié ;
- conflit avec Sarah si elle attend un geste.

Choix joueur :
- accepter pour respirer ;
- refuser pour rester disponible ;
- demander à Nico de servir d’alibi ;
- proposer de passer plus tard.

### Camille journée de travail

Camille peut écrire :
```text
pause de trois minutes.
j’en utilise une pour te dire que ta limite m’agace encore.
```

Fonctions :
- rendre son quotidien visible ;
- installer la tension dans un temps contraint ;
- rendre la discussion moins solennelle ;
- créer du désir contenu.

### Maya social

Maya peut écrire :
```text
bon. j’ai fait semblant de rien voir pendant presque 24h.
```

Fonctions :
- montrer que le social continue ;
- signaler que le groupe a une ambiance ;
- sans donner de preuve.

### Inès soir

Inès peut écrire :
```text
j’ai écrit trois messages et j’en ai effacé deux.
```

Fonctions :
- rendre l’hésitation visible ;
- éviter l’analyse parfaite ;
- rendre la douceur moins automatique.

## 12. Vie quotidienne et lieux

Chaque conversation devrait répondre implicitement à au moins une question :

- Où est le personnage ?
- À quel moment de la journée ?
- Pourquoi écrit-il maintenant ?
- Combien de temps a-t-il ?
- Est-il disponible ou distrait ?
- Quelle humeur porte-t-il ?

Pistes par personnage :

### Sarah

Lieux :
- cuisine ;
- table ;
- salon ;
- matin ;
- objet domestique.

État :
- fatigue ;
- attente ;
- tentative de croire aux gestes.

### Nico

- console ;
- bar ;
- trajet ;
- cuisine ;
- soirée.

État :
- retard ;
- vanne ;
- limite ;
- vraie disponibilité variable.

### Camille
