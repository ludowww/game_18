# J2 — Recadrage narratif

## 1. Problème identifié

Le Jour 2 est maintenant écrit sur cinq fils principaux : Sarah, Nico, Camille, Maya et Inès. Chaque scène fonctionne dans son intention locale, mais l’ensemble peut donner une impression de flottement si l’histoire commune n’est pas assez claire.

Le risque vient du fait que chaque personnage réagit à des flags, des choix ou des climats émotionnels sans que le socle commun soit explicitement verrouillé.

Pour éviter les incohérences, le J2 doit distinguer clairement :

- les faits ;
- les versions données ;
- les soupçons ;
- les interprétations ;
- les émotions ;
- les silences ;
- les traces sociales.

Un personnage ne doit jamais parler comme s’il lisait les variables du jeu. Il doit parler depuis ce qu’il a vu, entendu, ressenti ou compris de manière incomplète.

## 2. Vérité canonique minimale

Ce qui est vrai, quelle que soit la branche :

- Il y a eu une soirée ou un moment de groupe.
- Le joueur s’est absenté, éloigné, ou est devenu difficile à situer à un moment.
- Camille est liée à ce moment dehors, au moins émotionnellement.
- Sarah a senti que le joueur était ailleurs en rentrant.
- Nico peut avoir été sollicité, directement ou indirectement, pour couvrir ou tenir une version.
- Maya a remarqué des absences, des timings, une photo ou une attitude collective.
- Inès a perçu une faille émotionnelle, sans connaître les faits.
- Le joueur a passé une partie du J1 à gérer des versions différentes selon les personnes.

Ce qui ne doit pas être posé comme vérité commune :

- Camille ne constitue pas une preuve.
- Nico n’est pas automatiquement complice.
- Maya ne sait pas ce qui s’est réellement passé.
- Sarah ne connaît pas forcément la nature du moment avec Camille.
- Inès ne connaît pas les enjeux Sarah / Camille / Nico / Maya.
- Le groupe ne sait pas forcément quelque chose ; il peut seulement sentir un malaise.

Le moteur dramatique est donc : les versions commencent à peser, sans que la vérité soit encore explicitement exposée.

## 3. Ce qui doit rester ambigu

Le J2 ne doit pas encore trancher les grandes questions.

Doivent rester ambigus :

- ce que le joueur ressent vraiment pour Camille ;
- ce que Camille veut vraiment ;
- si Sarah sait quelque chose ou ressent seulement une distance ;
- si Maya a vu quelque chose de précis ou interprète des signaux ;
- si Nico couvre un mensonge ou seulement un flou ;
- si Inès est une ouverture sincère ou une fuite émotionnelle ;
- si le joueur cherche à réparer ou seulement à limiter les dégâts.

Le J2 ne doit pas résoudre l’histoire. Il doit rendre la situation plus dense et plus coûteuse.

## 4. Timeline claire J1 → J2

### J1 — soirée / nuit

- Moment de groupe.
- Absence, retrait ou flottement du joueur.
- Moment dehors ou tension avec Camille.
- Retour vers Sarah avec distance émotionnelle.
- Nico peut être associé à la version donnée.
- Maya peut remarquer des absences ou une photo.
- Inès perçoit une faille, mais ne connaît pas les faits.

### J1 — lendemain immédiat / journée

- Sarah demande où le joueur était et ce qui s’est passé.
- Camille demande si le moment dehors était “juste une discussion”.
- Nico demande ce qu’il est censé savoir ou dire.
- Maya pique sur les timings, le groupe et les absences.
- Inès propose une présence douce.
- Sarah repas ramène le conflit dans le domestique : assiette, pull, retour, retard.
- Nico respiration ramène de l’humour, mais aussi la question de l’alibi et du vrai conseil.

### J2 — matin

- Sarah revient sur la cohérence émotionnelle : présence, distance, versions.
- Nico revient sur l’alibi, la dette et la limite amicale.

### J2 — après-midi

- Camille revient sur la tension, la limite, la minimisation ou la pression.
- Maya revient sur le regard social : photo, timing, groupe, Sarah.

### J2 — soir

- Inès offre un espace calme, mais le risque de fuite doit être nommé.
- Inès ne doit pas devenir une romance explicite ni une solution gratuite.

## 5. Rôle exact de chaque personnage

### Sarah

Fonction dramatique :

- relation principale ;
- ancrage domestique ;
- demande de cohérence ;
- fatigue émotionnelle ;
- sentiment que le joueur est présent physiquement mais pas vraiment là.

Sarah sait :

- ce que le joueur lui a dit ;
- ce qu’elle a ressenti quand il est rentré ;
- si le joueur a parlé de Nico ou de Camille ;
- si le joueur est revenu manger, a retardé, a esquivé, ou a utilisé une excuse ;
- son propre malaise.

Sarah ne sait pas :

- ce qui s’est réellement passé avec Camille ;
- ce que Nico sait vraiment ;
- ce que Maya a observé exactement ;
- ce qu’Inès représente pour le joueur.

Erreur à éviter :

Sarah ne doit pas devenir une enquêtrice omnisciente. Elle ne doit pas parler comme si elle avait lu les scènes Camille, Nico ou Maya. Sa force vient du ressenti et de la cohérence émotionnelle, pas de la preuve.

### Nico

Fonction dramatique :

- ami ;
- potentiel alibi ;
- limite face à la dette ;
- humour qui protège mais ne règle pas tout.

Nico sait :

- ce que le joueur lui a demandé ;
- s’il a été mis dans une version ;
- s’il doit rester vague ou tenir une ligne ;
- s’il a reçu une vérité partielle sur Camille ;
- son propre inconfort.

Nico ne sait pas :

- ce que Sarah pense exactement ;
- ce que Camille ressent ;
- ce que Maya a vu ;
- la totalité des versions données ailleurs.

Erreur à éviter :

Nico ne doit pas devenir le commentateur global de la situation. Il peut sentir que quelque chose ne tient pas, mais il ne doit pas nommer tous les fils dramatiques comme s’il les avait vus.

### Camille

Fonction dramatique :

- tension affective ;
- limite ;
- refus d’être minimisée ;
- refus d’être un refuge pratique ;
- refus d’être une parenthèse.

Camille sait :

- ce qu’elle a vécu avec le joueur ;
- ce que le joueur lui a dit ;
- si le joueur a reconnu, minimisé, respecté une limite ou mis trop de pression.

Camille ne sait pas :

- la version exacte donnée à Sarah ;
- ce que Nico a accepté ou refusé ;
- ce que Maya observe ;
- ce qu’Inès représente.

Erreur à éviter :

Camille ne doit pas devenir “la tentation” ou “la voie romantique”. Elle doit surtout protéger la vérité de son propre vécu et refuser d’être utilisée par le trouble du joueur.

### Maya

Fonction dramatique :

- regard social ;
- groupe ;
- timing ;
- photo ;
- soupçon sans preuve.

Maya sait :

- les absences visibles ;
- les timings ;
- une photo ou un contexte de groupe ;
- des attitudes ;
- éventuellement que Sarah peut être affectée.

Maya ne sait pas :

- la vérité intime ;
- les conversations privées ;
- les versions exactes données à Sarah, Nico ou Camille ;
- le contenu émotionnel réel du moment dehors.

Erreur à éviter :

Maya ne doit pas devenir détective. Elle ne doit pas “prouver”. Elle doit observer, interpréter, piquer, protéger, et parfois se tromper.

### Inès

Fonction dramatique :

- calme ;
- présence douce ;
- faille émotionnelle ;
- risque de fuite.

Inès sait :

- que le joueur semblait loin ;
- ce que le joueur lui a dit ;
- s’il s’est ouvert, a gardé une distance, a cherché refuge, ou a été trop direct.

Inès ne sait pas :

- ce qui s’est passé avec Sarah ;
- ce qui s’est passé avec Camille ;
- ce que Nico couvre ;
- ce que Maya observe.

Erreur à éviter :

Inès ne doit pas devenir une romance explicite trop tôt. Elle ne doit pas être une récompense émotionnelle. Elle doit pouvoir offrir une présence, mais aussi refuser d’être une échappatoire.

## 6. Axe dramatique du Jour 2

Le Jour 2 ne doit pas répondre à la question : “qu’est-ce qui s’est passé ?”

Il doit répondre à une autre question :

**Comment les versions de la veille commencent-elles à peser sur les relations ?**

Chaque personnage porte un angle :

- Sarah : “Est-ce que tu es vraiment là avec moi ?”
- Nico : “Est-ce que tu me demandes d’être ton ami ou ton alibi ?”
- Camille : “Est-ce que tu vas reconnaître ce moment sans m’utiliser ?”
- Maya : “Est-ce que le groupe voit déjà quelque chose que tu refuses de nommer ?”
- Inès : “Est-ce que tu viens vers moi ou est-ce que tu fuis ailleurs ?”

Le J2 doit donc être une journée de conséquence, pas une journée de révélation.

## 7. Incohérences potentielles à chercher dans les dialogues actuels

### Incohérences de savoir

À vérifier :

- Sarah ne doit pas réagir à une information que seul Nico, Camille ou Maya possède.
- Nico ne doit pas parler comme s’il connaissait la scène Sarah ou Camille dans le détail.
- Camille ne doit pas supposer les versions données à Sarah.
- Maya ne doit pas parler comme si la photo prouvait quelque chose.
- Inès ne doit pas comprendre les enjeux relationnels qu’elle n’a pas vus.

### Incohérences de timeline

À vérifier :

- Les scènes J2 matin doivent venir avant les scènes après-midi.
- Sarah et Nico peuvent se répondre au matin, mais ne doivent pas présupposer ce qui se passe chez Camille ou Maya l’après-midi.
- Camille ne doit pas réagir à Maya J2 sauf branche future dédiée.
- Inès arrive le soir : elle peut sentir la fatigue, mais pas connaître la journée entière.

### Incohérences de choix

À vérifier :

- Chaque choix multiple doit répondre directement au dernier message affiché.
- Les choix ne doivent pas changer brutalement de sujet.
- Les choix “chercher refuge” doivent être préparés par une phrase de fatigue ou de calme.
- Les choix “limite” doivent être formulés comme une posture claire, pas une fuite déguisée.

### Incohérences de tonalité

À vérifier :

- Sarah ne doit pas être uniquement accusatrice.
- Nico ne doit pas être trop métaphorique ou trop clownesque.
- Camille ne doit pas être trop théâtrale ou trop tentatrice.
- Maya ne doit pas être trop sûre d’elle.
- Inès ne doit pas être trop disponible ou trop intime trop vite.

## 8. Principes de correction à appliquer ensuite

La tâche de correction suivante doit modifier uniquement les champs `text`.

Ne pas modifier :

- les ids ;
- les `next` ;
- les `effects` ;
- les flags ;
- les `entry_variants` ;
- la structure ;
- le runtime ;
- les médias ;
- les tests, sauf si les tests contiennent des attentes de placeholder obsolètes.

Les corrections doivent :

- rendre chaque scène plus lisible dans la timeline ;
- clarifier les savoirs réels de chaque personnage ;
- réduire les formulations trop abstraites ;
- réduire les métaphores trop nombreuses ;
- renforcer le lien entre dernier message et choix ;
- garder les personnages dans leur fonction dramatique.

## 9. Corrections recommandées par conversation

### Sarah J2

Statut général :
Sarah J2 est globalement solide. Elle porte bien la cohérence émotionnelle, le domestique, le retour ou non-retour, et la fatigue.

Points à surveiller :

- Certaines phrases peuvent être très belles mais un peu abstraites pour de la messagerie.
- Sarah doit rester dans le ressenti, pas dans l’analyse.
- Si Sarah parle de Nico, elle doit rester sur “j’ai senti qu’il faisait attention” plutôt que “je sais que tu l’as mis dans l’histoire”.

Corrections recommandées :

- Garder l’axe : présence, cohérence, version fragile.
- Simplifier les phrases trop littéraires.
- Renforcer la fatigue calme plutôt que l’accusation.

Priorité :
Recommandé.

### Nico J2

Statut général :
Après le polish T175-bis, Nico est plus naturel. Il reste drôle, mais plus humain.

Points à surveiller :

- Le dialogue doit éviter de devenir un commentaire global de l’histoire.
- Nico doit parler depuis son implication, pas depuis une connaissance générale des autres fils.
- Certaines formulations comme “version officielle” sont utiles, mais doivent rester rares.

Corrections recommandées :

- Garder les phrases courtes.
- Préserver “je peux faire simple, mais simple ça veut pas dire magique”.
- Éviter d’ajouter de nouvelles images ou métaphores.
- Faire de Nico un ami inquiet, pas un moteur de punchlines.

Priorité :
Optionnel, car T175-bis a déjà corrigé l’essentiel.

### Camille J2

Statut général :
Camille J2 remplit bien sa fonction : tension, limite, refus d’être minimisée ou utilisée.

Points à surveiller :

- Camille peut parfois sonner très lucide, presque trop formulée.
- Elle doit rester dans son vécu, pas analyser toute la situation du joueur.
- Quand elle parle de “les autres”, il faut s’assurer qu’elle ne semble pas connaître Sarah/Nico/Maya.

Corrections recommandées :

- Remplacer les formulations trop globales par des formulations centrées sur elle.
- Exemple de vigilance : “Je veux juste pas devenir le mot que tu utilises pour éviter les autres” peut rester, mais il faut vérifier qu’elle parle depuis son ressenti et non depuis une connaissance de tous les autres fils.
- Garder la ligne : “je ne veux pas être ton air de secours”.

Priorité :
Recommandé.

### Maya J2

Statut général :
Maya J2 est utile pour le regard social. Elle observe et pique, mais il faut veiller à ne pas la rendre trop sûre.

Points à surveiller :

- La photo doit rester ambiguë.
- Maya ne doit pas dire “je sais”.
- Elle peut dire “ça laisse une place bizarre”, “ça sonne précis”, “je dis pas que”.
- Elle ne doit pas devenir protectrice de Sarah de manière trop frontale si le joueur ne l’a pas poussée.

Corrections recommandées :

- Renforcer les formulations de doute :
  - “je crois”
  - “ça donne l’impression”
  - “je dis pas que”
  - “peut-être que je me trompe”
- Réduire les phrases trop accusatrices.
- Garder le ton piquant, mais pas policier.

Priorité :
Recommandé.

### Inès J2

Statut général :
Inès J2 respecte bien le calme, la fuite et la limite.

Points à surveiller :

- Inès ne doit pas être trop thérapeutique.
- Elle ne doit pas devenir trop mature / trop parfaite.
- Elle doit rester douce, mais aussi humaine, hésitante, capable de se protéger.
- Le choix “chercher refuge” doit être clairement risqué, pas récompensé.

Corrections recommandées :

- Ajouter ou conserver de petites hésitations.
- Éviter qu’elle formule trop parfaitement les dynamiques psychologiques.
- Garder le vocabulaire simple : “je ne veux pas être seulement ça”, “je peux rester là”, “je ne veux pas me perdre dedans”.

Priorité :
Recommandé.

## 10. Synthèse opérationnelle pour T180

La prochaine tâche T180 devra être une correction texte ciblée sur le J2 complet.

Objectif de T180 :

- ne pas réécrire toutes les scènes ;
- ne pas changer la structure ;
- ne pas changer les effets ;
- corriger uniquement les phrases qui :
  - donnent trop de savoir à un personnage ;
  - sonnent trop abstraites ;
  - ne raccordent pas bien avec les choix ;
  - rendent le ton trop fort trop tôt.

Méthode recommandée :

1. Lire les cinq JSON J2.
2. Lister les phrases à risque.
3. Remplacer uniquement les champs `text`.
4. Mettre à jour les tests seulement si des textes de choix changent et doivent rester alignés aux nodes player.
5. Relancer toute la validation.

Priorité pour T180 :

1. Maya, pour éviter l’effet détective.
2. Inès, pour éviter l’effet thérapeute / refuge gratuit.
3. Camille, pour réduire les formulations trop globales.
4. Sarah, léger polish seulement.
5. Nico, probablement très peu après T175-bis.

## 11. Décision narrative verrouillée

Le J2 doit désormais être compris comme :

**Le lendemain où chaque personnage ne découvre pas la vérité, mais ressent le poids des versions.**

Cette phrase doit guider toutes les corrections futures.
