# Jour 3 V2 — Brief narratif

## 1. Rôle narratif du Jour 3

Le Jour 3 V2 ne doit pas encore être l’explosion.

J1 pose les versions.
J2 fait peser ces versions sur chaque relation séparément.
J3 doit être le premier jour où certaines versions commencent à circuler, se frotter ou produire des effets indirects.

Phrase directrice :

> Le J3 n’est pas encore le jour de la vérité. C’est le jour où le joueur comprend qu’il n’est plus seul à gérer les versions.

Le rôle de J3 est donc de rendre le monde plus vivant sans transformer les personnages en enquêteurs omniscients. Les autres commencent à avoir leurs horaires, leurs échanges, leurs limites, leurs intuitions. Le joueur ne contrôle plus entièrement le rythme social.

## 2. Axe dramatique principal

Axe proposé : **contradictions contrôlées**.

Le joueur doit sentir :

- que Sarah observe davantage les gestes que les promesses ;
- que Nico n’est plus un simple alibi disponible ;
- que Camille refuse de rester une parenthèse silencieuse ;
- que Maya peut relier des signaux sociaux sans devenir détective ;
- qu’Inès peut rester une respiration, mais pas une fuite gratuite.

J3 doit augmenter la pression par friction, pas par révélation brutale.

Les contradictions peuvent apparaître via :

- un timing qui ne colle pas ;
- une gêne dans une formulation ;
- un message qui arrive au mauvais moment ;
- un personnage qui refuse d’être utilisé comme phrase de secours ;
- une remarque sociale indirecte ;
- une fatigue émotionnelle visible.

## 4. Personnages actifs J3 MVP

### Sarah J3

Rôle :

- relation principale ;
- place réelle dans la journée ;
- observation des gestes plutôt que des promesses ;
- conséquence directe des choix Sarah J2.

Sarah peut réagir à :

- `j2_sarah_try_concrete` ;
- `j2_sarah_asked_time` ;
- `j2_sarah_minimized_again` ;
- `j2_sarah_admitted_incoherence` ;
- `j2_sarah_version_fragile_named` ;
- `j2_nico_released_from_alibi` uniquement si le joueur le lui dit plus tard, pas automatiquement.

Sarah ne doit pas savoir :

- les choix exacts de Camille J2 ;
- les choix exacts de Nico J2 ;
- ce que Maya ou Inès ont dit ;
- les intentions internes du joueur.

Sarah doit rester centrée sur ce qu’elle voit : présence, évitement, concret, retard, cohérence, fatigue.

### Nico J3

Rôle :

- ami moins disponible ;
- alibi qui a un coût ;
- vie propre hors joueur ;
- possible premier signe d’une dynamique Nico ↔ Maya.

Nico peut réagir à :

- `j2_nico_hold_line` ;
- `j2_nico_released_from_alibi` ;
- `j2_nico_partial_truth_camille` ;
- `j2_nico_joke_escape` ;
- `j2_nico_alibi_cost` ;
- `j2_nico_friend_not_tool`.

Nico ne doit pas devenir :

- le narrateur omniscient ;
- le confident automatique de tout ;
- le clown permanent ;
- une preuve ambulante qui explique Sarah, Camille ou Maya.

Le ton de Nico doit pouvoir changer selon la dette et la fatigue : moins disponible, moins drôle, plus net sur ses limites.

### Camille J3

Rôle :

- tension qui ne peut plus rester seulement ambiguë ;
- conséquence du respect ou de la pression ;
- possible trace du dehors qui continue de résonner.

Camille peut réagir à :

- `j2_camille_assumed_tension` ;
- `j2_camille_clear_boundary` ;
- `j2_camille_minimized_again` ;
- `j2_camille_refuge_attempt` ;
- `j2_camille_pressure_rises` ;
- `j2_camille_no_false_promise` ;
- `j2_camille_respected_again`.

Camille ne doit pas savoir :

- les versions Sarah/Nico/Maya ;
- les stratégies d’alibi ;
- ce que Sarah ressent ;
- les échanges avec Inès.

Camille doit juger le joueur sur ce qu’il a fait avec elle : nommer, minimiser, presser, respecter ou chercher refuge.

### Maya J3

Rôle :

- regard social plus actif ;
- lien possible avec Sarah ou Nico ;
- début de circulation de signaux dans le groupe.

Maya peut réagir à :

- `j2_maya_asked_directly` ;
- `j2_maya_malaise_admitted` ;
- `j2_maya_defensive` ;
- `j2_maya_discretion_requested` ;
- `j2_maya_suspicion_grows` ;
- `j2_maya_social_read_opened` ;
- `j2_maya_group_boundary`.

Maya ne doit pas :

- prouver la vérité ;
- devenir détective ;
- parler au nom de Sarah ;
- déduire des faits invisibles.

Maya doit rester dans le social : elle voit les rythmes, les gestes, les silences, les raccords faibles.

### Inès J3

Rôle :

- respiration optionnelle ;
- miroir de fuite ou de clarté ;
- relation isolée des faits centraux.

Inès peut réagir à :

- `j2_ines_careful_opening` ;
- `j2_ines_boundary_kept` ;
- `j2_ines_refuge_attempt` ;
- `j2_ines_repair_misstep` ;
- `j2_ines_fuite_rises` ;
- `j2_ines_not_escape` ;
- `j2_ines_respected_distance`.

Inès ne doit pas :

- connaître Sarah, Camille, Nico ou Maya ;
- devenir une solution romantique immédiate ;
- récompenser la fuite ;
- transformer une ouverture douce en intimité acquise.

Inès peut être calme, mais ce calme ne doit pas servir d’échappatoire sans coût.

## 5. Structure J3 MVP proposée

J3 doit rester plus court que J2 au départ.

### Matin

- Sarah J3 : place réelle, gestes, matin prudent, demande de concret ou constat de distance.
- Nico J3 : disponibilité réduite, coût de l’alibi, vie propre.

### Après-midi

- Camille J3 : tension, limite, impossibilité de refaire comme si rien.
- Maya J3 : regard social, possible lien léger avec Nico ou Sarah.

### Soir

- Inès J3 optionnelle : calme, distance, réparation ou refus de devenir refuge.

Cette structure évite de refaire J2 avec une journée supplémentaire. Chaque bloc doit introduire un niveau de circulation ou de conséquence supplémentaire.

## 6. Premier croisement recommandé : Sarah ↔ Nico

Croisement recommandé J3 : **Sarah ↔ Nico**.

Pourquoi :

- c’est le croisement le plus préparé ;
- l’alibi a été utilisé, refusé, allégé ou alourdi ;
- Nico peut être libéré ou chargé ;
- Sarah peut être sensible au fait que la version “Nico” tienne mal.

Garde-fous :

- Sarah ne doit pas apprendre automatiquement ce que Nico a dit ;
- Nico ne doit pas rapporter la conversation Sarah ;
- Nico ne doit pas trahir gratuitement le joueur ;
- le croisement doit rester indirect.

Formes possibles :

- timing étrange ;
- gêne dans une réponse ;
- formulation mal raccordée ;
- Nico qui dit qu’il ne veut plus être “dans cette phrase” ;
- Sarah qui remarque une disponibilité ou une absence sans connaître le détail.

## 7. Deuxième croisement possible : Nico ↔ Maya

Croisement optionnel et léger : **Nico ↔ Maya**.

Rôle :

- montrer que Nico a une vie sociale hors joueur ;
- préparer une future dynamique Nico/Maya ;
- complexifier le groupe sans créer une trahison.

Exemples de niveau design :

- Nico mentionne que Maya lui a écrit ;
- Maya a fait une remarque à Nico ;
- Nico évite de dire exactement quoi ;
- le joueur comprend que les autres parlent aussi.

À ne pas faire :

- romance Nico/Maya immédiate ;
- trahison de Nico ;
- preuve donnée par Maya ;
- triangle spectaculaire ;
- Maya qui devient source d’exposition directe.

## 8. Variables clés J3

Variables à surveiller :

- `coherence` ;
- `risque_exposition` ;
- `fatigue_emotionnelle` ;
- `confiance_sarah` ;
- `distance_sarah` ;
- `dette_nico` ;
- `tension_camille` ;
- `respect_camille` ;
- `pression_camille` ;
- `suspicion_maya` ;
- `fuite_ines`.

Principe :

Les variables doivent commencer à influencer les tons et les variantes, pas forcément créer de gros embranchements.

Exemples :

- `coherence` basse : formulations plus fragiles, personnages plus prudents ;
- `risque_exposition` haut : timings plus dangereux, réponses moins confortables ;
- `fatigue_emotionnelle` haute : choix plus coûteux, silences plus visibles ;
- `dette_nico` haute : Nico moins disponible ou plus sec ;
- `pression_camille` haute : Camille plus froide ;
- `suspicion_maya` haute : Maya plus directe, toujours sans preuve ;
- `fuite_ines` haute : Inès pose une limite.

## 10. Médias J3

Pas de média obligatoire au début du MVP J3.

Possibilités futures prudentes :

- Nico : story floutée, date, bar, trace de vie sociale ;
- Maya : message social ou détail de groupe ;
- Sarah : trace domestique ou objet du quotidien ;
- Camille : trace plus intime seulement si respect haut et pression basse ;
- Inès : image calme seulement si la relation ne sert pas de fuite.

À ne pas ajouter en J3 MVP :

- média explicite niveau 3 ou 4 ;
- média comme récompense de branche ;
- preuve visuelle compromettante ;
- image qui rend une route objectivement “meilleure”.

Les médias Camille/Inès de J2 restent acceptables, mais doivent être surveillés en playtest car ils rendent leurs branches plus attractives.

## 11. Risques à éviter

- Explosion trop tôt ;
- tous les personnages qui parlent de la même chose ;
- Sarah omnisciente ;
- Maya détective ;
- Nico qui trahit le joueur sans préparation ;
- Nico réduit au clown ou à l’outil d’alibi ;
- Inès romance-fuite ;
- Camille récompense sexuelle ;
- trop de variantes combinées dès le départ ;
- refaire J2 avec une journée de plus ;
- résoudre la contradiction au lieu de la faire circuler.

## 12. Proposition MVP J3

MVP recommandé : créer d’abord une structure technique J3 V2 avec placeholders, puis écrire seulement :

1. Sarah J3 matin ;
2. Nico J3 matin.

Pourquoi :

- ce sont les deux axes du premier croisement ;
- ils permettent de tester la circulation indirecte des versions ;
- ils donnent un signal clair sur la disponibilité de Nico et la vigilance de Sarah ;
- Camille, Maya et Inès peuvent venir ensuite sans surcharger la première passe.

Ce MVP permet aussi de valider le passage J2 → J3 sans écrire immédiatement cinq conversations complètes.

Pour les dialogues :

- required conversations J3 à définir ;
- Inès optionnelle si le design conserve la logique J2 ;
- pas de média explicite ;
- pas de connaissance automatique Sarah ↔ Nico.

## 15. Recommandation de priorité pour T190

Priorité recommandée : **Option A — structure J3 V2 courte, puis Sarah/Nico seulement**.

Ordre conseillé :

1. créer la structure technique J3 V2 avec placeholders ;
2. déclarer Sarah/Nico J3 comme conversations de départ ;
3. garder Camille/Maya/Inès verrouillées ou non écrites dans un premier temps ;
4. écrire Sarah J3 matin ;
5. écrire Nico J3 matin ;
6. tester le croisement indirect Sarah ↔ Nico ;
7. repousser les variantes combinées et médias à une tâche ultérieure.

Ne pas faire maintenant :

- écrire les cinq conversations J3 d’un coup ;
- ajouter des médias J3 ;
- créer une explosion narrative ;
- rendre Sarah, Maya ou Nico omniscients ;
- transformer Inès en issue de secours romantique ;
- corriger J2 pendant la mise en place de J3.

Décision proposée avant J3 :

> Valider un J3 MVP court centré Sarah/Nico, avec contradictions indirectes et conséquences de disponibilité, puis étendre Camille/Maya/Inès après un premier playtest de transition J2 → J3.
