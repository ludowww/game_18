# Bible de production narrative long terme — J4+

## 0. Statut

Document de cadrage pour la production narrative après stabilisation J1/J2/J3 V2.

Cette bible ne crée pas J4. Elle définit la méthode, les arcs longs, les modules narratifs et les critères de validation à respecter avant toute nouvelle écriture.

Contraintes de T205 :

- aucun JSON modifié ;
- aucun script modifié ;
- aucun test modifié ;
- aucun asset ajouté ;
- documentation uniquement.

## 1. Pourquoi changer de méthode

J1/J2/J3 V2 ont permis de valider le socle : dialogues, choix, effets, médias, progression, oralité et premières tensions croisées.

Mais la méthode actuelle montre ses limites :

- trop de corrections réactives après écriture ;
- trop d’allers-retours sur les mêmes scènes ;
- personnages écrits conversation par conversation, parfois trop isolés ;
- temporalité et disponibilité ajoutées tardivement ;
- dynamiques interpersonnages encore peu anticipées ;
- médias et intimité cadrés après coup ;
- routes futures non préparées assez tôt ;
- risque de multiplier des journées “cohérentes” mais trop mécaniques.

La production J4+ doit passer d’une logique :

```text
écrire scène → auditer → corriger → repolir
```

à une logique :

```text
cadrer journée + arcs longs + modules → écrire blocs ciblés → tester cohérence et rythme → playtest
```

L’objectif n’est pas de rigidifier l’écriture. L’objectif est de donner assez de structure pour que les dialogues puissent être plus vivants sans casser les savoirs, les routes ou le rythme.

## 2. Vision long terme du jeu

Double Vie doit rester un jeu de messagerie où le drame vient moins de “révélations” que de la pression accumulée entre :

- ce que le joueur dit ;
- ce qu’il tait ;
- le moment où il répond ;
- les personnes qu’il sollicite ;
- les gestes qu’il tient ou ne tient pas ;
- les contradictions visibles dans le quotidien.

La promesse long terme :

> Le téléphone n’est pas seulement une interface de choix. C’est un espace social vivant où chaque réponse crée un climat.

J4+ doit donc renforcer :

- les journées incarnées ;
- les temporalités lisibles ;
- les disponibilités variables ;
- les relations qui se croisent sans omniscience ;
- les médias comme traces, pas preuves ;
- l’intimité comme conséquence de respect, pas récompense mécanique ;
- l’amitié comme ressource limitée ;
- le couple comme quotidien à tenir, pas seulement problème à expliquer.

## 3. Principes non négociables

### 3.1 Pas d’omniscience

Chaque personnage ne sait que :

- ce qu’il a vécu ;
- ce que le joueur lui a dit ;
- ce qu’il peut observer socialement ;
- ce qui est plausible dans son environnement.

Maya peut sentir une ambiance. Elle ne doit pas devenir détective.
Sarah peut observer les gestes. Elle ne doit pas connaître les conversations privées.
Nico peut aider ou refuser. Il ne doit pas trahir gratuitement.
Camille peut tester les limites. Elle ne doit pas devenir une récompense sexuelle.
Inès peut offrir du calme. Elle ne doit pas devenir thérapeute ou refuge automatique.

### 3.2 Pas de preuve absolue par média

Une image déplace le climat. Elle ne tranche pas la vérité.

Interdit :

- photo qui prouve une faute ;
- photo privée non consentie ;
- capture qui révèle une conversation ;
- média intime comme récompense ;
- image sexualisée avant préparation et consentement.

### 3.3 Le désir doit être préparé

La tension sexuelle future, surtout avec Camille, doit venir de :

- respect ;
- pression basse ;
- limites tenues ;
- désir nommé par étapes ;
- initiative du personnage concerné ;
- temporalité crédible.

Elle ne doit jamais venir de :

- culpabilité ;
- dette ;
- fuite ;
- manipulation ;
- score de drague ;
- récompense visuelle automatique.

### 3.4 Les choix doivent créer un climat

Chaque choix important doit idéalement toucher au moins un axe :

- confiance ;
- distance ;
- dette ;
- pression ;
- respect ;
- cohérence ;
- risque ;
- fuite ;
- intimité ;
- fatigue émotionnelle.

Mais les variables ne doivent pas remplacer l’écriture. Elles soutiennent le climat, elles ne l’expliquent pas à la place des scènes.

## 4. Trajectoires longues par personnage

### 4.1 Sarah — quotidien, confiance, gestes

Rôle long terme : cœur domestique et affectif du jeu.

Sarah n’est pas seulement “celle qui soupçonne”. Elle est celle qui vit avec le joueur, observe le quotidien et mesure l’écart entre les phrases et les gestes.

Trajectoire possible :

- J1 : malaise, premières versions, besoin de place.
- J2 : demande de concret, fatigue, premières limites émotionnelles.
- J3 : observation des gestes, attente, matin domestique.
- J4+ : conséquences visibles des gestes tenus ou non tenus.
- J5+ : confiance fragile ou distance installée.
- Finale : reconstruction possible, rupture douce, confrontation ou compromis bancal selon cohérence et respect.

Axes à suivre :

- `confiance_sarah` ;
- `distance_sarah` ;
- `intimite_sarah` ;
- cohérence entre promesses et gestes ;
- disponibilité réelle du joueur.

À produire avant chaque journée Sarah :

- que voit-elle concrètement aujourd’hui ?
- quel geste attendu est tenu ou absent ?
- parle-t-elle depuis la demande, la fatigue, ou le constat ?
- que sait-elle réellement ?
- qu’est-ce qui reste conjugal et tendre malgré la tension ?

Risques :

- Sarah trop juge ;
- Sarah trop diagnostique ;
- Sarah réduite à “épouse blessée” ;
- intimité conjugale utilisée comme réparation rapide.

### 4.2 Nico — amitié, alibi, vie propre

Rôle long terme : ami, soupape, limite, miroir comique et coût de l’alibi.

Nico doit rester drôle, mais pas clown permanent. Il peut aider, mais son aide a un coût relationnel. Il doit aussi avoir une vie hors joueur.

Trajectoire possible :

- J1 : respiration, vanne, soutien léger.
- J2 : alibi coûteux, limites d’ami.
- J3 : vie propre, sortie, gaming, disponibilité variable.
- J4+ : choix entre aide réelle, refus, fatigue ou proposition de respiration saine.
- J5+ : amitié renforcée ou abîmée par l’usage répété comme pare-feu.

Axes à suivre :

- `dette_nico` ;
- fatigue émotionnelle ;
- cohérence des versions ;
- disponibilité de Nico ;
- possible dynamique Nico ↔ Maya sans exposition prématurée.

Modules spécifiques :

- soirée jeux vidéo ;
- alibi demandé explicitement ;
- Nico refuse de “gérer” ;
- Nico aide mais aggrave par humour ou fatigue ;
- Nico a une vie sociale que le joueur ne contrôle pas.

Risques :

- conseiller conjugal ;
- traître narratif ;
- clown permanent ;
- outil d’alibi sans conséquences.

### 4.3 Camille — tension, limites, désir futur

Rôle long terme : axe principal de tension désirante, mais conditionnée au respect.

Camille ne doit jamais devenir une récompense sexuelle. Elle doit avoir son propre rythme, son travail, ses pauses, sa lucidité et ses limites.

Trajectoire possible :

- J1/J2 : ambiguïté, dehors, tension reconnue ou minimisée.
- J3 : limites testées, pause/travail, tension verbale.
- J4 : désir davantage nommé si respect haut et pression basse.
- J5+ : média plus suggestif ou scène plus intime seulement si la route est préparée.
- Finale : relation assumée, refus net, tension non consommée ou conséquence douloureuse selon choix.

Axes à suivre :

- `respect_camille` ;
- `pression_camille` ;
- `tension_camille` ;
- `intimite_camille` ;
- minimisation ou reconnaissance ;
- usage de Camille comme refuge ou non.

Avant d’écrire une scène Camille :

- est-elle au travail, en pause, en trajet, dans un lieu chargé ?
- teste-t-elle une limite ou une vérité ?
- exprime-t-elle un désir propre ou répond-elle à une pression ?
- le joueur a-t-il gagné le droit narratif d’approcher ?

Risques :

- tension sexuelle accélérée ;
- Camille trop théorique ;
- Camille qui explique sa fonction ;
- Camille récompense de “bonne” réponse.

### 4.4 Maya — social, groupe, signaux

Rôle long terme : circulation sociale, ironie, piques, observation des ambiances.

Maya ne doit pas être détective. Elle doit être dans le social : elle voit les décalages, les silences, les changements de sujet, les humeurs de groupe.

Trajectoire possible :

- J1 : photo de groupe, première perception.
- J2 : malaise social, discrétion demandée.
- J3 : signaux qui se répondent, piques sans preuve.
- J4+ : groupe qui devient plus vivant, rumeurs faibles, invitations, contradictions visibles.
- J5+ : choix entre protéger le groupe, confronter, plaisanter ou se retirer.

Axes à suivre :

- `suspicion_maya` ;
- `risque_exposition` ;
- cohérence sociale ;
- dynamique de groupe ;
- degré de discrétion demandé par le joueur.

Modules spécifiques :

- story floue ;
- groupe qui répond bizarrement ;
- changement de sujet ;
- Maya remarque un timing ;
- Maya protège quelqu’un sans dire qui.

Risques :

- preuve sociale ;
- détective ;
- porte-parole omnisciente ;
- exposition trop brutale.

### 4.5 Inès — calme, hésitation, fuite ou présence

Rôle long terme : espace de douceur, mais pas refuge gratuit.

Inès doit rester lente, hésitante, présente sans envahir. Sa route devient intéressante si le joueur cesse de l’utiliser comme cachette.

Trajectoire possible :

- J1/J2 : respiration, calme, fenêtre, prudence.
- J3 : hésitation, messages effacés, limite entre présence et refuge.
- J4+ : relation plus vraie seulement si fuite basse et distance respectée.
- J5+ : désir possible mais très prudent, jamais thérapeutique ou réparateur.

Axes à suivre :

- `fuite_ines` ;
- distance respectée ;
- intimité douce ;
- disponibilité du soir ;
- capacité du joueur à ne pas se cacher.

Avant d’écrire Inès :

- pourquoi écrit-elle maintenant ?
- qu’a-t-elle effacé ou retenu ?
- est-elle choisie comme personne ou utilisée comme refuge ?
- quel silence reste volontaire ?

Risques :

- thérapeute ;
- récompense de calme ;
- refuge romantisé ;
- lucidité trop parfaite.

## 5. Dynamiques interpersonnages J4+

Les fils doivent se croiser sans que les personnages deviennent omniscients.

### 5.1 Sarah ↔ Nico

Usage : alibi, temporalité, disponibilité.

Exemple de module : Sarah remarque un détail qui ne colle pas. Le joueur peut répondre immédiatement ou contacter Nico avant de répondre.

Effets possibles :

- réponse plus cohérente mais plus tardive ;
- dette Nico augmente ;
- confiance Sarah baisse si délai visible ;
- cohérence monte si alibi propre ;
- risque exposition monte si Nico fatigue.

Garde-fou : Nico ne doit pas connaître Sarah autrement que par ce que le joueur lui dit.

### 5.2 Sarah ↔ Camille

Usage : tension entre quotidien conjugal et désir extérieur.

Le croisement doit être indirect : gestes domestiques d’un côté, pause/travail/tension de l’autre. Pas de confrontation frontale trop tôt.

Questions :

- le joueur répond-il à Camille pendant qu’un geste Sarah est attendu ?
- Camille sent-elle qu’elle devient une sortie ?
- Sarah observe-t-elle une absence sans savoir pourquoi ?

### 5.3 Nico ↔ Maya

Usage : vie sociale hors joueur, groupe, humour, possible dynamique future.

À garder subtil : Nico peut être indisponible pour une raison sociale, Maya peut sentir une ambiance de groupe, mais aucun média ou dialogue ne doit révéler trop tôt une relation identifiable.

### 5.4 Camille ↔ Maya

Usage : social + tension.

Maya peut percevoir une ambiance autour de Camille sans savoir ce qui s’est passé. Camille peut craindre de devenir visible dans un groupe.

Garde-fou : Maya ne doit jamais “savoir” une scène privée.

### 5.5 Inès ↔ Sarah / Camille

Usage : fuite ou vraie respiration.

Inès doit révéler le rapport du joueur à l’évitement. Si le joueur répond à Inès au lieu de tenir un geste Sarah ou une limite Camille, le jeu peut le sentir par les variables, mais Inès ne doit pas le formuler comme une connaissance omnisciente.

## 6. Modules futurs possibles

### 6.1 Module temporalité

Objectif : rendre les blocs de journée sensibles.

Blocs utiles :

- début de matinée ;
- pause midi ;
- après-midi/travail ;
- fin de journée ;
- soirée ;
- nuit plus tardive.

Implémentation recommandée d’abord par dialogue :

- “pause de trois minutes” ;
- “je viens de rentrer” ;
- “je lance la console” ;
- “j’ai écrit trois messages et j’en ai effacé deux”.

UI dédiée possible plus tard : cartes de transition, mais seulement après design spécifique.

### 6.2 Module disponibilité

Chaque personnage devrait avoir une disponibilité variable :

- Sarah : disponible mais usée ;
- Nico : variable, parfois occupé ;
- Camille : pauses/travail ;
- Maya : social/groupe ;
- Inès : soir/silence.

But : éviter les conversations qui semblent toutes attendre le joueur dans le vide.

### 6.3 Module croisements

Permettre au joueur de consulter un fil avant de répondre à un autre.

Exemples :

- Sarah → contacter Nico avant réponse ;
- Camille → demander conseil à Nico ;
- Maya → temporiser pour éviter exposition ;
- Inès → choisir respiration ou fuite.

À cadrer avant runtime : quels croisements sont MVP, quels effets, quelles limites d’interface.

### 6.4 Module alibi

Nico est le candidat naturel, mais l’alibi doit coûter.

Choix possibles :

- demander alibi ;
- refuser d’utiliser Nico ;
- dire une demi-vérité ;
- répondre tard sans alibi.

Conséquences : dette, cohérence, risque, confiance Sarah.

### 6.5 Module médias

Règles :

- média = trace ou climat ;
- toujours suivi d’une réaction ou mini-discussion ;
- pas de preuve ;
- pas de contenu intime sans consentement ;
- pas de récompense mécanique.

J4+ peut utiliser :

- traces domestiques Sarah ;
- lieux de Camille ;
- sorties Nico ;
- groupe Maya ;
- calme Inès.

### 6.6 Module intimité

Intimité future par niveaux :

1. quotidien / présence ;
2. intimité émotionnelle ;
3. suggestif ambigu ;
4. sensuel adulte ;
5. explicite adulte éventuel.

Conditions minimales pour monter :

- consentement ;
- respect ;
- pression basse ;
- cohérence suffisante ;
- désir exprimé par le personnage ;
- route préparée sur plusieurs scènes.

### 6.7 Module humeur

Les personnages devraient porter une humeur du jour :

- Sarah : fatiguée mais attentive ;
- Nico : léger mais moins disponible ;
- Camille : concentrée, troublée ;
- Maya : piquante, sociale ;
- Inès : hésitante, douce.

L’humeur n’est pas un label affiché. Elle doit se sentir dans l’ouverture, les délais, la longueur des messages, les choix proposés.

## 7. Méthode de production d’une journée J4+

### Étape 1 — Cadrage macro

Avant toute scène :

- rôle narratif de la journée ;
- niveau de pression ;
- ce qui doit avancer ;
- ce qui doit rester futur ;
- quels personnages actifs ;
- quels croisements autorisés ;
- quels modules utilisés.

Sortie attendue : doc courte de cadrage.

### Étape 2 — Carte de temporalité

Définir :

- matin ;
- pause/midi ;
- après-midi ;
- soirée ;
- nuit si nécessaire.

Pour chaque bloc :

- qui écrit ;
- pourquoi maintenant ;
- combien de temps disponible ;
- quel risque de collision.

### Étape 3 — Matrice personnage

Pour chaque personnage :

- humeur du jour ;
- lieu ou activité ;
- savoirs disponibles ;
- savoirs interdits ;
- objectif de la scène ;
- signature de voix ;
- risque à éviter.

### Étape 4 — Carte des croisements

Lister seulement les croisements utiles.

Pour chaque croisement :

- déclencheur ;
- fil source ;
- fil consulté ;
- conséquence ;
- garde-fou anti-omniscience ;
- test à prévoir.

### Étape 5 — Choix et effets avant écriture

Avant les dialogues complets, définir les postures de choix :

- posture honnête ;
- posture d’évitement ;
- posture de pression ;
- posture de respect ;
- posture d’alibi ou de temporisation.

Puis seulement écrire les messages.

### Étape 6 — Écriture en blocs

Écrire par bloc temporel, pas par personnage isolé.

Exemple :

1. matin Sarah/Nico ;
2. pause Camille/Maya ;
3. soirée Nico/Inès/Sarah ;
4. croisements nécessaires.

### Étape 7 — Tests narratifs avant tests techniques

Avant les tests Python :

- chaque personnage sait-il seulement ce qu’il peut savoir ?
- chaque scène a-t-elle une raison temporelle ?
- chaque média a-t-il une réaction ?
- chaque choix change-t-il un climat ?
- y a-t-il trop de répétitions de structure ?

### Étape 8 — Tests techniques

Créer les tests ensuite :

- entry variants ;
- single replies ;
- choix/player identiques ;
- flags/effects ;
- médias ;
- unlocks ;
- non-omniscience ;
- non-régression.

## 9. Critères de validation avant écriture

Ne pas écrire une journée tant que ces questions n’ont pas une réponse claire.

### 9.1 Journée

- Quel est le rôle narratif de la journée ?
- Qu’est-ce qui augmente ?
- Qu’est-ce qui reste non révélé ?
- Quel est le niveau de pression cible ?
- Quel est le risque principal ?

### 9.2 Personnages

Pour chaque personnage :

- où est-il ?
- pourquoi écrit-il maintenant ?
- que sait-il ?
- que ne sait-il pas ?
- quelle humeur porte-t-il ?
- quel est son objectif relationnel ?
- quelle signature de voix doit dominer ?

### 9.3 Choix

- Les choix représentent-ils des postures claires ?
- Les textes player sont-ils naturels ?
- Les effets correspondent-ils à la posture ?
- Les choix évitent-ils les récompenses mécaniques ?

### 9.4 Croisements

- Quel fil influence quel autre fil ?
- Est-ce visible sans omniscience ?
- Le joueur comprend-il le coût du délai ?
- Les variables soutiennent-elles cette collision ?

### 9.5 Médias

- Le média est-il nécessaire ?
- Est-il suivi d’une réaction ?
- Déplace-t-il l’ambiance sans prouver ?
- Respecte-t-il consentement et non-explicite ?
- Peut-il être remplacé plus tard sans changer le JSON ?

### 9.6 Intimité

- La scène accélère-t-elle trop ?
- Le consentement est-il clair ?
- La pression est-elle basse ?
- Le personnage exprime-t-il son désir propre ?
- Est-ce une conséquence relationnelle ou une récompense ?

## 10. Format conseillé pour les briefs J4+

Chaque brief de journée devrait contenir :

1. résumé de la journée ;
2. rôle dramatique ;
3. pression cible ;
4. blocs temporels ;
5. personnages actifs ;
6. savoirs autorisés/interdits ;
7. croisements ;
8. médias éventuels ;
9. routes intimes éventuelles ;
10. flags/variables à utiliser ;
11. tests à prévoir ;
12. choses interdites pour cette journée.

## 12. Définition de “prêt à écrire”

Une journée J4+ est prête à écrire seulement si :

- son rôle dramatique tient en une phrase ;
- ses blocs temporels sont définis ;
- chaque personnage a lieu, humeur, objectif et savoirs ;
- les croisements utiles sont choisis ;
- les médias éventuels sont justifiés ;
- les routes intimes sont bornées ;
- les variables/flags principaux sont anticipés ;
- les tests à écrire sont listés ;
- les interdits de la journée sont explicites.

Si une de ces cases manque, produire un document de design avant les dialogues.

## 13. Conclusion

J1/J2/J3 ont stabilisé le socle. J4+ doit maintenant éviter l’écriture en silo.

La priorité n’est pas d’écrire plus vite une grande quantité de messages. La priorité est de préparer mieux : temporalité, croisements, disponibilité, intimité, médias, variables et savoirs.

Une journée réussie doit donner l’impression que les personnages vivent pendant que le joueur répond.

La méthode J4+ recommandée :

```text
brief macro → temporalité → matrice personnages → croisements → effets/routes → écriture par blocs → audits ciblés → playtest
```

Cette bible devient la référence de production narrative long terme pour les tâches T206+.
