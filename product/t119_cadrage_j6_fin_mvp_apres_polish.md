## Fonction dramatique post-polish

J6 répond à la question :

> Quand la double vie n’est plus invisible, quelle version de toi tu choisis d’assumer ?

Mais cette question doit être écrite par des messages concrets, pas par des phrases-thème.

À éviter dans J6 :

- personnages qui disent frontalement “ta double vie”, “les traces”, “les conséquences”, “le coût” ;
- procès final unique ;
- avalanche de choix “avouer / mentir / esquiver” ;
- fins qui expliquent le score au joueur ;
- Sarah détective, Camille ultimatum, Maya omnisciente, Nico sauveur, Inès troisième route complète.

À viser :

- détails domestiques ;
- téléphone regardé trop souvent ;
- phrase vue par quelqu’un ;
- alibi qui fatigue un ami ;
- message laissé en attente ;
- une place qu’on ne sait plus ranger ;
- choix final clair mais pas didactique.

## Structure J6 retenue

Structure MVP conservée depuis T115, mais avec respiration explicite :

```txt
S6A → C6A → N6A → M6A → S6B → C6B → I6A → FIN
```

Lecture post-polish :

1. `S6A` — Sarah ouvre par un détail quotidien qui ne tient plus.
2. `C6A` — Camille demande une position, mais via un lieu / un téléphone / un silence.
3. `N6A` — Nico pose une limite d’ami, avec humour et fatigue.
4. `M6A` — Maya relève un détail social concret, pas une “preuve”.
5. `S6B` — Sarah demande une vérité émotionnelle simple.
6. `C6B` — Camille demande à ne plus être une parenthèse.
7. `I6A` — Inès revient comme porte latérale, signe de fuite possible, court.
8. `FIN` — choix final MVP : Sarah / Camille / contrôle / fissure / fuite optionnelle.

## Règle de pression J6

J6 est la journée de résolution, donc la pression augmente, mais elle ne doit pas être constante.

Ratio recommandé J6 :

- 25 % respiration humaine ;
- 35 % pression douce ;
- 40 % pression forte.

Même en final, chaque contact doit avoir au moins une ligne ou mini-échange qui rappelle qu’il existe hors de la crise.

Exemples :

- Sarah : “j’ai laissé ton mug dans l’évier, j’ai pas eu le courage de le ranger.”
- Camille : “j’ai remis le même morceau qu’hier. mauvaise idée.”
- Nico : “j’ai commandé trop de frites. c’est pas le sujet mais ça m’aide à réfléchir.”
- Maya : “j’ai failli rien dire. puis j’ai revu la photo.”
- Inès : “j’ai écrit trois versions de ce message. celle-ci est la moins étrange.”

## Rôles contacts J6 post-polish

### Sarah — vérité intime, pas enquête

Sarah ne cherche pas des preuves. Elle cherche à savoir si elle peut encore habiter la relation.

Elle doit partir du quotidien :

- repas ;
- appartement ;
- message attendu ;
- objet ;
- fatigue ;
- soirée où elle rentre tard ;
- sensation d’être seule à deux.

Objectif de blocs :

- `S6A` : ouvrir par un détail concret qui montre que la confiance fatigue.
- `S6B` : demander une réponse émotionnelle simple : “tu veux encore être là, ou tu veux juste que ça tienne ?”

Interdits :

- “j’ai des preuves” ;
- interrogatoire ;
- scène de jalousie mécanique ;
- vocabulaire de système.

### Camille — position claire, pas ultimatum caricatural

Camille doit rester lucide, attirante, dangereuse par sa justesse.

Elle ne demande pas forcément “choisis-moi maintenant”. Elle refuse surtout d’être rangée dans un coin du téléphone.

Objectif de blocs :

- `C6A` : une proposition ou un message qui force le joueur à reconnaître qu’il regarde encore son téléphone pour elle.
- `C6B` : une demande de respect : pas être une parenthèse, pas être l’endroit où respirer quand le reste pèse.

Interdits :

- ultimatum brutal unique ;
- récompense romance automatique ;
- répétition `dette/coût/trace` ;
- jalousie trop frontale envers Sarah.

### Nico — ami loyal, pas outil

Nico doit servir de respiration et de limite.

Il peut faire rire, mais il doit montrer que couvrir quelqu’un finit par impliquer sa propre parole.

Objectif bloc :

- `N6A` : Nico refuse de devenir standard téléphonique / alibi permanent. Il peut aider une dernière fois selon confiance, mais pas tout porter.

Interdits :

- tutoriel moral ;
- sauvetage magique ;
- “personnage secondaire” méta ;
- phrases trop écrites.

### Maya — détail social, pas omniscience

Maya n’a pas tout compris. Elle a vu assez.

Objectif bloc :

- `M6A` : elle met sur la table un détail social concret : photo, horaire, phrase de groupe, “il est où ?” lancé trop vite, story vue, contradiction légère.

Interdits :

- enquête ;
- révélation policière ;
- expliquer la morale ;
- centraliser la fin romantique.

### Inès — porte latérale, pas troisième romance complète

Inès revient brièvement parce que J5 l’a laissée en réserve.

Son rôle : révéler la tentation de fuite. Le joueur peut être tenté de choisir une échappatoire plutôt qu’une personne.

Objectif bloc :

- `I6A` : message court, hésitant, nocturne ou à contretemps. Elle ouvre une porte sans exiger que le joueur la franchisse.

Interdits :

- route complète ;
- grande déclaration ;
- “preuve/mensonge” frontal ;
- triangle supplémentaire lourd.

## Fins MVP retenues

T119 conserve les fins T115, mais reformule leur intention post-polish.

### Fin A — Réparation fragile

Le joueur choisit Sarah / présence / vérité partielle.

Ton : pas victoire, pas pardon instantané. Une tentative de rester.

Image textuelle possible : Sarah ne range pas encore le mug / accepte de parler demain / laisse une porte ouverte.

### Fin B — Camille assumée

Le joueur choisit Camille comme relation réelle, pas comme refuge.

Ton : attirant mais coûteux humainement. Sarah n’est pas effacée par magie.

Image textuelle possible : Camille ne répond pas tout de suite, puis demande une phrase simple, pas belle.

### Fin C — Double vie maintenue

Le joueur garde le contrôle pour l’instant.

Ton : tension calme, inconfortable. Ça tient, mais le téléphone reste lourd.

Image textuelle possible : aucune explosion, juste une notification qui arrive trop tard.

### Fin D — Tout se fissure

Le joueur a trop esquivé / trop utilisé les autres.

Ton : pas forcément scène publique ; plutôt silence, distances, messages qui ne reviennent pas.

Image textuelle possible : Nico ne couvre plus, Sarah répond froidement, Camille coupe court.

### Fin E — Fuite en avant / solitude

Optionnelle.

Le joueur refuse de choisir et se raccroche à l’ambiguïté Inès ou au silence.

Ton : pas romance bonus. Fin de fuite, pas récompense.

Image textuelle possible : le joueur ouvre un nouveau message au lieu de répondre aux anciens.
