# T002 — Pitch court

## Pitch retenu

**Double Vie** est un jeu narratif adulte en fausse messagerie où chaque notification peut devenir une tentation, un mensonge ou une preuve.

Le joueur gère ses échanges avec Sarah, sa partenaire officielle, Camille, une relation ambiguë qui s’installe trop vite, et Nico, confident plus ou moins fiable. Chaque réponse laisse une trace : confiance gagnée ou perdue, désir entretenu, risque accumulé, culpabilité silencieuse.

La promesse : **ressentir l’addiction aux messages avant l’addiction aux images**, puis assumer les conséquences d’une double vie qui se construit bulle après bulle.

## Version ultra-courte

Un simulateur de double vie relationnelle où chaque message peut devenir une opportunité, un mensonge, une preuve ou une crise.

## Pitch Discord / store court

Dans **Double Vie**, votre téléphone est votre terrain de jeu — et votre pire ennemi. Flirtez, mentez, temporisez ou avouez dans une messagerie intime où chaque choix modifie les relations, les traces et les risques. Les messages arrivent vite. Les conséquences aussi.

## Piliers exprimés dans le pitch

- Séduction : Camille crée l’appel du risque.
- Secret : Sarah rend chaque absence suspecte.
- Risque : chaque réponse peut devenir une trace.
- Conséquences : les petits mensonges reviennent plus tard.
- Messages d’abord : l’attente et la notification sont le moteur principal.
